> **Легковесное, высокопроизводительное нативное Windows-приложение на C++ (GDI+ / Win32 API).**  
> Снежинки плавно скапливаются в реалистичные сугробы на крышах активных окон, исчезают при касании, не забивают экран и автоматически засыпают в играх (0.00% ЦП).

---

## 🌟 Основные особенности (Features)

### 🏔️ 1. Накопление сугробов на крышах окон (Snowdrifts)
- Падающие снежинки аккуратно собираются на верхних гранях открытых окон (Браузер, Проводник, Блокнот и т.д.) в виде **плавной снежной шапки / холмика**.
- **Физика осыпания (Angle of Repose)**: сугроб формирует естественный закругленный холм, не образуя острых пиков.
- **Чистое исчезновение**: излишки снега на сугробе и по краям окон аккуратно растворяются на месте, **не ссыпаясь струями с углов** и не загромождая экран.
- **Привязка к окну**: сугроб перемещается плавно вместе с окном при его перетаскивании.

### 🎮 2. Умный игровой режим (Game Mode: 0.00% ЦП)
- **Двойной детектор**:
  - `SHQueryUserNotificationState` определяет запуск Direct3D / Vulkan / OpenGL полноэкранных игр.
  - Геометрический детектор определяет игры в режиме «окно без рамок» (Borderless Fullscreen).
- **Полная заморозка**: как только вы играете или смотрите полноэкранное видео, приложение **полностью останавливает отрисовку и физику**, сбрасывая нагрузку на ЦП и GPU строго до **0.00%**.
- При возврате на рабочий стол (Alt+Tab) снег моментально возобновляется на 60 FPS.

### ⚡ 3. Ультра-низкое потребление ресурсов
- Написано на чистом C++20 с оптимизацией `-O3` и статической сборкой.
- Никакого Python или тяжёлых фреймворков.
- Потребление оперативной памяти: всего **~11 МБ**, процессор: **~1%** (вместо 20% в скриптовых аналогах).

### 🧹 4. Чистый экран
- Снежинки, достигающие нижней границы экрана или панели задач, **мгновенно исчезают** и возрождаются сверху. Внизу экрана сугробы не скапливаются.
- Аппаратная маска окна (`ExcludeClip`): снежинки физически **никогда не попадают внутрь окон**, текст и интерфейс остаются кристально чистыми.

### 🎨 5. Центр кастомизации и стилей
- **5 быстрых пресетов в 1 клик**:
  - `🏔️ Сказка`: крупные пышные сугробы на окнах, мягкий снегопад.
  - `❄️ Метель`: быстрый плотный снег с порывами ветра.
  - `🌟 Свечение`: нежные светящиеся ореолы вокруг хлопьев.
  - `🌈 Неон`: неоновый киберпанк (cyan, magenta, violet, ice mint).
  - `⚡ Эко`: ультра-легкий режим (0.1% ЦП).
- **Детальная настройка**:
  - Скорость роста сугробов на окнах (от 0x до 3.0x).
  - Максимальная толщина сугроба (до 60 пикселей).
  - Скорость таяния сугробов.
  - Размер снежинок (от мелкой крупки 1.5 px до хлопьев 7.5 px).
  - Скорость падения и направление ветра.
  - 5 цветовых палитр (Белый, Ледяной синий, Золотистый, Неоновый циан, Неоновый розовый).
  - 5 стилей отрисовки хлопьев (*Пушистый*, *Свечение*, *Кристаллы ❄*, *Неон*, *Точки*).
- **Кнопка «🧹 Сбросить сугробы»**: мгновенная очистка всех окон.

## 🛠️ Сборка из исходников (Build)

Для сборки требуется компилятор `g++` (MinGW-w64 с поддержкой C++17/20):

```cmd
git clone https://github.com/aarabiik/desktop-snow.git
cd desktop-snow
build.bat
```

Либо вручную одной командой:
```cmd
g++ -O3 -mwindows -std=c++17 -static -static-libgcc -static-libstdc++ main.cpp -o DesktopSnowNative.exe -lgdi32 -luser32 -ldwmapi -lgdiplus -lcomctl32 -lwinmm -lshlwapi -lole32 -lshell32
```

---

## 🚀 Запуск и управление

1. Запустите `DesktopSnowNative.exe`.
2. Перед вами откроется панель настроек в тёмной теме Windows 11.
3. В системном трее (возле часов) появится иконка ❄:
   - Клик левой кнопкой — открыть / скрыть настройки.
   - Клик правой кнопкой — меню быстрого сброса сугробов, паузы или выхода.
